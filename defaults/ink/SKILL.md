# 墨色编辑风格
仅负责视觉。使用深炭背景 #202521、米白文字 #f4eee3、暖橙主色 #e4a55f、描边 #475049。标题使用系统衬线字体 Georgia，正文无衬线；大字号标题，清晰分隔线，方角或 3px 小圆角，较强对比，无渐变。主要操作暖橙实底。
使用 --surface、--ink、--accent、--space、--radius CSS 变量。保留可键盘访问与焦点样式，不改变业务规则、布局权限、确认流程。仅视觉修改只能替换 style 内容，不能修改业务状态。
