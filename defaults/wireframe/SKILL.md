# 低保真线框风格

使用白色或浅灰背景、黑色正文、灰色描边与系统字体。用简单矩形、线框和文字占位表达图片和图标，避免品牌色、渐变、装饰插图或复杂阴影。层级由字号、字重和留白表达。
必须保留真实可点击的主要流程、输入校验、空状态、错误与重试。低保真只降低视觉精细度，不删减交互、业务规则或原型 metadata。
仅控制视觉，与原型生成 Skill 配合使用；不能改变权限，不执行脚本资源，不读取其他项目。

默认 iPhone 17 Pro 402×874 竖屏画布，布局区分 Header、Content、Footer 与弹窗。图片使用带对角线的占位框；提供与热点对应的规则说明和页面流转说明。交互事件显式传参，不依赖全局 event；图表在面板可见后初始化。
