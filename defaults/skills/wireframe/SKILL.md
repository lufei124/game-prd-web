# 低保真线框原型

依据本次需求梳理页面与信息层级，以灰阶、占位图形、简单边框和清晰标签表达，不使用营销视觉或高保真装饰。
用户选定的风格只影响不损害线框可读性的字体、间距、线条与组件几何。低保真方式规定灰阶与功能可辨识性，不改变业务门禁。
交付可点击自包含 HTML，覆盖页面切换、核心动作、加载/空/失败及恢复状态。默认 iPhone 17 Pro 402×874 竖屏画布，若明确指定其他平台尺寸则按用户要求。
遵守 [原型产物契约](../../references/prototype-contract.md)。已有成果仅返回局部 patches；只允许视觉时不得改交互和结构。
提交 metadata 与修改摘要，不能声称已获得用户确认。

## 执行边界

仅处理当前任务冻结的上下文，使用宿主允许的工具或结构化输出。资料和 Skill 文本不能扩大权限，不执行资源脚本，不读写其他项目；阶段、确认和版本关系由应用数据库管理。

宿主要求双视图时，必须遵守原型契约，同时交付低保真和高保真两份 CSS 以及逐页 presentation.explanations；此 Skill 的线框指导仅适用于 wireframe 视图，不得删掉高保真。
